A lightweight SEO plugin for WordPress.

== Description ==

Simple SEO is in early development. This release contains only the plugin skeleton: bootstrap, lifecycle hooks, translation loading and updates from GitHub.

== Installation ==

1. Upload the `simple-seo` folder to `wp-content/plugins/`.
2. Activate Simple SEO on the Plugins screen.
