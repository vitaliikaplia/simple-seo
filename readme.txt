A lightweight SEO plugin for WordPress.

== Description ==

Simple SEO is in early development. So far it has the groundwork: SEO title and description fields for posts, pages and terms, a settings page with per-role access, and a single place for the plugin's tags in the page head. It does not print anything on the site yet.

== Installation ==

1. Upload the `simple-seo` folder to `wp-content/plugins/`.
2. Activate Simple SEO on the Plugins screen.
